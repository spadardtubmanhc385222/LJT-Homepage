# LJT-Homepage

Personal academic homepage of Junteng Liu, first-year Ph.D. candidate at the HKUST NLP Group, Hong Kong University of Science and Technology.

- Website: https://spadardtubmanhc385222.github.io/LJT-Homepage/
- Built on the [Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template, forked from `academicpages/academicpages.github.io`.

## Content

- About page (personal details, academic background, research experience, publications, awards, contact): `_pages/about.md`
- Publications: `_publications/` (shown on the Publications page and listed in the About section)
- Site-wide settings: `_config.yml`; header menu: `_data/navigation.yml`
